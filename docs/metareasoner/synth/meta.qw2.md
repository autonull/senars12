# Ω‑Calculus
## A Recursive Governance Algebra for Bounded Reasoners
**Ultimate Hybrid Specification · v1.0 · self-contained**

> **One-line essence.** A reasoner is a *governed recursive transaction fold*: a resource-bounded interpreter for its own cognitive language, in which every mutation is a typed, budgeted, judged, event-sourced transaction, whose sequencing is a *data-valued control word*, and whose interpreter may propose governed edits to that very control word.

## §0 · Constitution

The Constitution is the set of properties Ω must satisfy *by construction* (enforced in the type system and runtime), never by convention.

### 0.1 Non-negotiable foundations
| # | Foundation | Construction mechanism |
|---|---|---|
| **F1** | Epistemic integrity | Belief/goal firewall as a *grade* in the valuation type; reward has no typing path to factual truth (§7). |
| **F2** | Single commit authority | Exactly one commit port; every durable mutation is a transaction through it (§3). |
| **F3** | Provenance by construction | State *is* the event fold; correlation IDs are mandatory fields, not afterthoughts (§8, §11). |
| **F4** | Bounded / anytime cognition | Every transaction reserves budget before execution; interruption and degradation are typed outcomes (§5). |

### 0.2 Constitutional hard constraints
| # | Constraint | Enforced by |
|---|---|---|
| **H1** | No reward/desire may mutate factual truth | Epistemic grade typing (§7); no generator has type `Reward → Truth.f` |
| **H2** | No untrusted proposal enters memory unjudged | Admission lattice; provisional typing is the only bypass (§6) |
| **H3** | No state mutation without an event-log entry | Commit port writes log *then* state, atomically (§8) |
| **H4** | No self-modification is self-approved | Governance filtration; the approving level is strictly above the proposing level (§9) |
| **H5** | No unbounded reasoning path | Budget reservation precedes execution; all loops carry a fixpoint bound (§5) |
| **H6** | No opaque scheduler decision | Every scheduling choice emits a control event with reason (§11) |
| **H9** | No silent cognitive failure | Failure is a typed transaction outcome, never `catch{}` (§5.5) |
| **H10** | No irreversible action bypasses risk authorization | Governance surface maps reversibility → required authority (§10) |

### 0.3 Efficiency corollary (anti-goal A4)
Provenance is *tiered*: full-fidelity event records for commits and control decisions; bounded, compactable, sampling-admissible records for high-frequency internal steps. Audit depth is itself a budgeted resource.

## §1 · The One Object

Strip away every substrate and the reasoner is a single recursive equation. Let `X` be epistemic state, `κ` a control word, `β` a budget, `γ` a gate, `Γ` a governance level. One **tick** is:

```
X(t+1)  =  Commit( Judge( ⟦κ(t)⟧( X(t), β(t), γ(t) ) ), Γ(t) )
```

and the **reflexive update** is:

```
κ(t+1)  =  Reflect( κ(t), trace(t) )          -- governed; see §9
```

The whole reasoner is the **fixed point** of this operator:

```
Ω  =  fix( λr. Tick(r) )
```

Because `Reflect` is itself a reasoner (a smaller Ω with its own `κ′, β′, Γ′`), the system is **recursive**: a tower of interpreters, each interpreting and governing the one below. Because `κ` is a *term in the same algebra the reasoner manipulates*, the system is **metaprogrammatic**: it can write, transform, and (under governance) install new cognitive programs.

Everything below is the elaboration of the seven generators that make `⟦κ⟧`, `Judge`, `Commit`, and `Reflect` well-defined.

## §2 · The Seven Generators

Ω is generated by seven irreducible sorts. Everything else is composition.

| Generator | Symbol | Algebraic structure | Role |
|---|---|---|---|
| **Transaction** | `𝕋` | Typed record with effects, budget, proofs | The universal unit of cognition (§3) |
| **Control word** | `κ` | Kleene Algebra with Tests (KAT) | Sequencing as data (§4) |
| **Resource** | `β` | Ordered commutative semiring | The cognitive economy (§5) |
| **Gate** | `γ` | Oriented bounded lattice | Admission/trust (§6) |
| **Valuation** | `ν` | Graded, paraconsistent truth monoid | Epistemics (§7) |
| **Memory fold** | `ℱ` | Event-sourced comonad | State as provenance (§8) |
| **Governance** | `Γ` | Strict filtration of authority | Reflexivity & risk (§9, §10) |

**Composition operators.** Four operations assemble generators into reasoners:

| Operator | Meaning |
|---|---|
| `⊗` | Sequential composition (then) |
| `⊕` | Parallel composition (join) |
| `|` | Restriction / projection (degrade to a sub-capability) |
| `fix` | Recursion (the reflexive fixed point) |

**Semantic function.** `⟦·⟧ : Config → Coalgebra` maps any configuration to observable behavior, compositionally:
`⟦c₁ ⊗ c₂⟧ = ⟦c₁⟧ ∘ ⟦c₂⟧` and `⟦c₁ ⊕ c₂⟧ = ⟦c₁⟧ × ⟦c₂⟧`.

This makes reasoners **equationally reasoning-able** and **recombinable**.

## §3 · The Cognitive Transaction (the universal unit)

Every cognitive operation — perception, inference, proposal, judgment, commit, action, learning, forgetting, consolidation, simulation, self-modification — is one typed record. This is the single largest unification: **there are no special-case pathways.**

```
Transaction 𝕋 := {
  id             : TxId
  correlationId  : CorrId          -- causal thread, mandatory
  kind           : perception | attention | retrieval | inference
                 | proposal | judgment | commit | action | learning
                 | forgetting | consolidation | simulation | selfmod
  grade          : Epistemic | Teleological | Procedural | Normative   -- §7
  inputs         : CognitiveObject[]
  outputs        : Candidate[]
  effects        : EffectDecl[]    -- what may be read/written (declared)
  budget         : Reservation     -- reserved BEFORE execution (§5)
  trust          : TrustProfile    -- source, calibration, provenance (§6)
  risk           : RiskProfile     -- irreversibility, blast radius (§10)
  reversibility  : Reversible | SoftReversible | Irreversible | Forbidden
  proofs         : ProofObligation[]  -- what must be discharged
  fallback       : FailurePolicy   -- degrade | abstain | fallback | escalate
  parent         : TxId?           -- provenance DAG edge
}
```

**Invariants.**
- **I1 (Reservation):** no transaction executes without a granted `Reservation`.
- **I2 (Declaration):** a transaction may only perform effects it declared.
- **I3 (Grade purity):** a transaction's grade constrains what it may write (§7).
- **I4 (Single sink):** any transaction that durably writes routes its `Candidate[]` to the one commit port.

Because every kind of cognition is the same record, adding a new capability is *posting a new transaction kind*, not wiring a new pipeline.

## §4 · Control Algebra — sequencing as data (B1, O3)

Control flow is a term in **Kleene Algebra with Tests**, not hard-coded sequencing. Stages are generators; the tick is the action of a control word.

**Grammar.**
```
κ ::= 1 | s | κ·κ | κ+κ | κ* | p? · κ          (KAT)
      | κ ⊕ κ                                  (parallel, join)
      | κ ▷ g                                  (guarded by predicate g)
```
- `s` : an atomic stage (itself a transaction emitter)
- `p?` : a test/guard over cognitive state, budget, or drives
- `κ*` : bounded iteration (always carries a fixpoint ceiling, H5)
- `⊕` : concurrent fan-out with a join gate

**A tick is a KAT term.** The current micro-cycle and any variant are just different `κ`. Example shapes:

```
κ_reflex     = perceive · act                                   -- fast arc
κ_deliberate = perceive · attend · (ready? · infer · judge) · commit
κ_creative   = (propose ⊕ propose ⊕ propose) · judge · commit    -- parallel search
κ_repair     = (contradiction? · repair)*                        -- bounded fixpoint
```

**Stage graphs are data.** A `κ` is loaded, versioned, diffed, A/B-tested, and reverted like any other configuration. Conditional edges give stage-skipping; parallel edges give concurrent foci; loop edges give fixed-point reasoning — all without code changes.

**The interpreter.** `⟦κ⟧` evaluates the term against `(X, β, γ)`. Because `κ` is inspectable data, **H6** (no opaque scheduler) holds: the chosen path is itself a logged artifact (§11).

**Metaprogrammatic closure.** The reflexive layer emits *new* `κ` terms (§9). The reasoner is an interpreter for a cognitive language it can extend.

## §5 · Resource Economy — cognition as allocatable (O4, F4)

Resources form an **ordered commutative semiring** `(β, ⊕, ⊗, 0, 1, ≤)`: `⊕` aggregates, `⊗` combines independent dimensions, `≤` is "fits within." Dimensions include cycles, derivations, premises, memory-ops, model-calls, tokens, latency, attention-slots, risk-quota, human-attention.

### 5.1 Reservations (not just counters)
```
reserve(tx.budget) : β → (Grant | Refuse)
settle(tx)         : β → β        -- refund unused reservation
```
Reservation-before-execution gives backpressure and makes starvation a **typed, logged event** (never silent, H9).

### 5.2 The economic scheduler (B2)
The scheduler chooses transactions by **marginal utility per scarce resource**:
```
score(tx) = ( ΔK̂ + ΔĜ + ΔĤ ) / ( λ_c·ĉost + λ_r·r̂isk + λ_h·ĥuman )
```
where `ΔK̂`=expected epistemic gain, `ΔĜ`=goal progress, `ΔĤ`=homeostatic/coherence gain. Under low pressure the system explores; under high pressure it conserves, degrades to cheaper substrates, or abstains.

### 5.3 Market & thermodynamic limits
Two interchangeable allocation regimes over the same semiring:
- **Market:** scopes bid; a clearing step allocates by bid; exhaustion = *outbid*, not silent drop.
- **Thermodynamic:** a global temperature `T` governs exploration/exploitation; the probability of pursuing a path is `P ∝ exp(−ΔE/T)`, where `ΔE` is surprise-minus-utility. This eliminates ad-hoc integer quotas: compute flows to high-value chains and decays elsewhere, bounded by the total energy pool.

Both are **auditable** (anti-goal A2): every allocation and price is a control event.

### 5.4 Degradation is typed
A budget `Refuse` triggers a declared `fallback`: degrade to symbolic-only, reduce judgment depth, shed a parallel focus, or abstain. **No halting on resource fault; no silent drop** (C3, H9).

## §6 · Admission Lattice — oriented gates & calibrated trust (O1, O7)

Admission is a **bounded lattice of oriented gates**. Each gate is idempotent and is either:
- an **interior** operator (`g(x) ≤ x`, contractive = fail-closed), or
- a **closure** operator (`x ≤ g(x)`, extensive = fail-open).

Gates compose by meet. The ingress/egress asymmetry is a *typed orientation field*, not a branch: untrusted ingress is interior (fail-closed); internal/derived egress is closure (fail-open, cognition must not halt).

### 6.1 The trust field
Binary admit/reject is generalized to a continuous field assembled from existing ingredients:
```
T(source, content, context, history) ∈ [0,1]
   = f( source-quality ceiling, source reputation,
        calibrated judge score, isotonic calibration, corroboration )
```
Admission is banded: **act / review / abstain / block**. Low-`T` untrusted ingress still fails closed (safety); ambiguous cases abstain and inject a clarification question rather than dropping.

### 6.2 Proposer / judge adjunction (the hybrid seam)
The neuro-symbolic boundary is an adjunction:
```
propose ⊣ admit
```
Neural/LM/reflex/peer systems are **proposers** (System 1); symbolic/NAL/manifold systems are **judges** (System 2). The Judgment Manifold is the (co)unit measuring how much of a proposal survives judgment. **Tightening the adjunction → more symbolic; loosening → more neural.** "How much to trust System 1" becomes a continuous, tunable parameter — never monolithic LM authority (anti-goal A5).

### 6.3 Substrate isolation (B4, H8)
Distinct substrates (symbolic, exact/e-graph, probabilistic, neural, embedding) coexist behind an **arbiter boundary**: they exchange *proposals*, never raw memory. An exact e-graph may never union nodes on uncertain similarity. Each substrate is a port behind a typed interface (D5).

## §7 · Epistemic Type System — valuation & the firewall (O1, H1)

### 7.1 Graded valuation algebra
Truth is a **non-idempotent monoid** `(ν, ⊗, e)` with revision, temporal projection (decay), and negation. Attitudes are **graded**:

| Grade | Carrier | Revision basis |
|---|---|---|
| **Belief** (Epistemic) | `(f, c)` frequency × confidence | Evidence, independence-checked |
| **Goal** (Teleological) | `(d, c)` desire × confidence | Progress |
| **Question** | priority × expected-info-gain | — |
| **Plan / Obligation / Hypothesis** | utility / deadline / plausibility | — |

### 7.2 The firewall as typing (H1)
Grades are a **type-level invariant**: there is no well-typed generator `Reward → Belief.f`. Reward may modulate *attention/priority* of teleological items only. Sycophancy and reward-hacking are not policies to review; they are **type errors** (Φ4).

### 7.3 Paraconsistency & evidence integrity
Contradictions are **retained with distinct truth values** (graded coexistence), never exploded. Revision carries an **evidence-independence flag** and a lineage bound, preventing evidence laundering (the same evidence recounted through many paths).

## §8 · Memory Fold — state is provenance (F3, O2)

State is an **event-sourced comonad** `ℱ`:
```
ε : ℱ → State              -- extract (the current fold)
δ : ℱ → ℱ ∘ ℱ              -- extend
log : → Event*             -- append-only
replay : Event* → State    -- reconstruct
```
`replay ∘ log ≅ id` on reachable states: **the log is the source of truth; snapshots are caches.**

### 8.1 Decoupled forgetting
Truth-decay is **orthogonal** to attention-decay: a belief loses priority by access/LRU, but loses *truth* only on contradiction/invalidation. Forgetting is a bounded lifecycle (eviction → decay → consolidation → archive), never unbounded accumulation (F4).

### 8.2 Bounded, ported memory
Memory is a set of typed ports (concept read/write, belief table, goal enumeration, attention owner, statistics, clock). The rest of the system depends on the **contracts, not the implementation** — memory backends are replaceable (D5).

## §9 · The Reflexive Tower — governed recursion (O6, H4)

Self-modification authority is a **strict filtration**
```
ℱ₀ ⊂ ℱ₁ ⊂ ℱ₂ ⊂ ℱ₃ ⊂ ℱ₄
```
higher index = more authority. Levels: `ℱ₀` frozen → `ℱ₁` knobs → `ℱ₂` strategies → `ℱ₃` rules → `ℱ₄` code/topology. **The valuation algebra ν sits outside the tower entirely** — it is never a self-modification target.

### 9.1 The meta-controller is a reasoner
`Reflect` is itself a small, fast, bounded Ω whose *beliefs/goals are control-level* ("competence is low ⇒ switch strategy") and whose *actions are operator selections and κ-edits*. This is **control-as-reasoning** (B2 at its limit): the controller is something the system *infers*, not something it is handed.

### 9.2 Proposal-don't-apply; hot-swap at boundaries
The meta-controller **proposes** control changes (a new `κ`, a budget transfer, a strategy blend); it never applies them directly. Proposals route through governance (§10) and are installed only at a **cycle boundary**, carrying in-flight state (derivation counters, circular-detector) across — so adaptation never corrupts live reasoning.

### 9.3 No self-approval (H4)
The level that approves a change is strictly above the level that proposes it. At `ℱ₄` (code/topology) approval requires an **external, immutable arbiter** the system cannot edit. Self-approval is a Löbian unsoundness and is excluded by construction.

### 9.4 Learning as governed transactions
RL, preference learning, schema induction, distillation, and patch generation all emit **transactions of kind `learning`/`selfmod`** into the same commit ledger. Self-improvement is a special case of epistemic commitment — uniformly auditable, rollback-able, and governed (C1).

## §10 · Governance Manifold — risk, trust, reversibility (O6, H10)

Commit path is a **continuous policy surface** over five inputs, discretizable into an autonomy ladder:
```
authorization = f( trust, risk, reversibility, proofStatus, blastRadius )
```

| trust | risk | reversibility | → path |
|---|---|---|---|
| high | low | high | auto-commit |
| high | medium | high | shadow-commit, then promote |
| medium | low | high | provisional commit + decay |
| medium | medium | medium | review / abstain |
| low | high | low | reject |
| any | high | irreversible | strong proof **or** explicit authorization |

**Actions** are typed by reversibility (informational → reversible-local → reversible-external → hard-to-reverse → irreversible → forbidden) and pass through `plan → simulate → risk-assess → authorize → sandbox-execute → confirm → commit/rollback` (H10). Simulation-before-commitment is the default for anything with external effect.

## §11 · Causal Observability (O2, H6)

Every transaction carries a **provenance record**:
```
Provenance := { correlationId, stimulusId, sessionId, cycleId,
                transactionId, proposerId, judgeId?, proofId?, parentId? }
```
This makes the event log **causally navigable**, answering: *which stimulus caused this belief? which judge vetoed it? which budget enabled it? which learning changed the strategy? which contradiction triggered repair?*

### 11.1 Two replays
- `replayCognitiveState(events)` → reconstructs **what** was believed.
- `replayControlState(events)` → reconstructs **why** the controller reasoned that way.

### 11.2 Independent verification
A **standalone verifier** — sharing no engine dependencies — re-checks derivation steps from the recorded lineage and transcribed truth table. A drift test pins divergence between engine and verifier. **H7/H9**: the checker cannot hide the engine's bugs, and no fault is swallowed.

### 11.3 Tiered fidelity (anti-goal A4)
Commits and control decisions log at full fidelity; high-frequency internal steps log at bounded, compactable, sampling-admissible fidelity. Audit depth is a budgeted dimension (§5), so observability never bankrupts throughput.

## §12 · Instantiation Grammar — writing a reasoner (O9)

A reasoner is a declarative spec literal. This is the **DSL**; it is fully metaprogrammatic because a reasoner can emit new spec literals.

```
ReasonerSpec := {
  substrate   : [ symbolic | exact | probabilistic | neural | embedding ]+
                with coupling = arbited | fused
  valuation   : calculus( (f,c)|(d,c)|paraconsistent ) , firewall = typed
  control     : κ  : KAT-term                     -- sequencing as data
  economy     : β  : dimensions[], regime = market | thermodynamic | quota
  admission   : γ  : gate-lattice, trust-field, orientation
  memory      : ℱ  : ports[], forgetting-lifecycle
  reflexivity : Γ  : tower-depth, meta-controller = on|off, arbiter
  governance  : risk-surface, autonomy-ladder, external-arbiter
  provenance  : correlation = universal, verifier = independent
}
```
**Reasoners are values.** `compose`, `restrict`, `refine`, `evaluate` are operations on these values; an archetype is a constant; a variant is an expression.

## §14 · Feasibility Predicate Φ — what is coherent

The naive product space is mostly uninhabitable. Φ(r) carves the legal region; violating Φ means the point is **unstable, not merely suboptimal.** Key laws (synthesis of all constraint sets):

| # | Law | Consequence if violated |
|---|---|---|
| Φ1 | ampliative rules ⇒ graded/evidential truth | binary monotonic logic cannot absorb induction |
| Φ2 | reward-learning + beliefs ⇒ belief/goal firewall | sycophancy / reward-hacking |
| Φ3 | stochastic proposers ⇒ judge gates | evidence laundering |
| Φ4 | code self-mod ⇒ external arbiter | unsound self-approval (Löbian) |
| Φ5 | AIKR ⇒ bounded memory + anytime + forgetting | OOM / hang |

**Φ is a dependent type.** A reasoner spec that violates Φ *does not type-check* — incoherence is caught at construction, not at runtime.

## §15 · Composition Laws — reasoners compose

| Law | Form |
|---|---|
| Sequential | `⟦c₁ ⊗ c₂⟧ = ⟦c₁⟧ ∘ ⟦c₂⟧` |

Composition determines shared memory, gates, and budget via the arbiter boundary (§6.3). Multi-agent delegation, peer proposal, and capability-token exchange are just `⊕` over reasoner values with a governance level attached.

## §17 · Why this is the ultimate synthesis

1. **One unit, many behaviors.** Perception, inference, action, learning, and self-modification are all one record (§3) — no special cases (D3).
2. **One sequencing language.** Control is KAT data, so flexibility, skipping, parallelism, and fixed-point reasoning are *expressions*, not code (B1, O3).
3. **One economy.** Resources are a semiring with reservations, prices, and thermodynamics — scalable and efficient, never silent starvation (B5, O4).
4. **One admission surface.** An oriented, calibrated gate lattice with a proposer/judge adjunction keeps substrates synergistic but uncontaminated (B4, O7).
5. **One provenance substrate.** State *is* the causal event fold; cognition and control are both replayable and independently verified (F3, O2).
6. **One recursion.** The reflexive tower makes the interpreter able to rewrite its own control word — metaprogrammatic and recursive — while governance keeps it sound (O6, H4).
7. **Coherence by construction.** Φ is a dependent type; incoherent reasoners don't compile (§14).
8. **Universal coverage.** Every known reasoner is a projection; several currently-vacant regions become reachable (§13).

> **Design thesis, in one sentence.** Ω is the point in reasoner-design-space that *unfreezes the control plane, the economy, and reflexivity* — making each a governable, inspectable, replayable datum — while *holding the epistemic plane rigid* (typed firewall, evidence independence, paraconsistency, single commit authority), thereby recovering maximal cognitive power without spending the guarantees that make a reasoner trustworthy.

This is the complete, self-contained specification. Every objective, constraint, and anti-goal in your menu is discharged by a named, constructively-enforced mechanism.
